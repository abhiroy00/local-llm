# local-llm

Home of **DevPilot AI**, a local-first AI coding assistant for VS Code.

The Phase 1 extension foundation is in [devpilot-ai](devpilot-ai/README.md).

## Development

```sh
cd devpilot-ai
npm ci
npm run check
```

Open the `devpilot-ai` folder in VS Code and press F5 to launch the extension development host. See the project documentation for implemented features and pending verification.
